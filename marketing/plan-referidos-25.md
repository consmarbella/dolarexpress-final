# Plan de Referidos DolarExpress — 2% de Comisión

## Cómo funciona

Cada vez que un referido tuyo vende su cupo en dólares con nosotros, **recibes el 2% del monto total vendido**.

### Ejemplo real:
```
US$1.000 vendidos por tu referido
Tu 2%: $17.880 CLP
```

| Venta del referido | Tu 2% |
|-------------------|--------|
| US$500 | **$8.940** |
| US$1.000 | **$17.880** |
| US$1.500 | **$26.820** |
| US$3.000 | **$53.640** |
| US$5.000 | **$89.400** |

---

## Sistema de tracking (sin app, solo WhatsApp)

### Opción 1: Código de referido manual
Cada referido tiene un código único: `REF-NOMBRE` (ej: REF-JUAN)
Lo menciona al contactarnos por WhatsApp.

### Opción 2: Link único de WhatsApp
```
wa.me/56967658939?text=Hola%20vengo%20por%20REF-JUAN%2C%20quiero%20vender%20mi%20cupo
```

## Reglas

| Concepto | Regla |
|----------|-------|
| Comisión | **2% del total vendido por el referido** |
| Pago | Después de cada venta concretada |
| Mínimo | No hay |
| Método | Transferencia a CuentaRUT |
| Vigencia | Vitalicia mientras esté activo |
| Límite | Sin límite |
| Autoreferido | No permitido |
